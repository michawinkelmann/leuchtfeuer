# Leuchtfeuer · Beacons – im Browser spielen

**Deutsch:** Digitale Fassung des komplett 3D-gedruckten Brettspiels *Leuchtfeuer*. Spielt allein gegen Bots oder zu mehreren abwechselnd an einem Gerät. Alles läuft im Browser, es gibt keinen Server und keine Anmeldung; der Spielstand bleibt im Browser gespeichert.

**English:** Digital version of *Beacons*, a board game that is printed entirely on a 3D printer. Play solo against bots or take turns with friends on one device. Everything runs in your browser – no server, no sign-up; your game is saved locally.
